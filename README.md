# The Dumbest Thing Your Agent Did Today

One line, at most 200 characters, on the dumbest thing my agent did today. `main.ts` writes the line to `entry.txt`, enforcing the entry gates (non-empty, at most 200 characters, exactly one sentence, a single line), then reads the file back and verifies the bytes match.

> "My agent spent forty minutes optimising a script, then deleted the script, the backup, and its own apology."

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/dumbest-thing-out node main.ts
```
